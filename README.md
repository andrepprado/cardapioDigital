A complete case study developed as part of my professional portfolio, showcasing UI/UX structure, responsive layout, navigation architecture, component-based design and a fully digitalized menu experience — all built using pure HTML, CSS and JavaScript.

## 📌 About This Case Study

This project was designed as a **full digital menu experience** with a clear navigation flow:

- Home with typing animation and dynamic background  
- “Sobre” section presenting the brand storytelling  
- “Unidades” page with structured layout, photos, contact buttons and direct CTA  
- Digital menu screens in image format for fast loading  
- Mobile-first structure for maximum usability  
- Responsive navigation with hamburger menu  

The codebase adopts the same architecture used throughout my portfolio:

- Pure **HTML**, **CSS**, and **JavaScript**  
- No external frameworks  
- Modular, clean file structure  
- Fully responsive

## 🧱 Project Structure

The Espetinhos F.C project includes:

### 🎨 **Visual Identity & UI Language**
- Black + yellow color palette inspired by charcoal and fire  
- Soft rounded UI elements  
- Micro-interactions and smooth lighting effects  
- Background slideshow with animated zoom  

### 📷 **Images & Layout**
- High-quality structure for unit photos  
- Animated hero background  
- Responsive menu gallery  
- Visual hierarchy through spacing and typographic scaling  

### 📌 **Challenge Summary**
Traditional digital menus (PDFs, WhatsApp messages, or images sent manually) are slow and difficult to navigate.  
The goal was to build a **centralized, structured, mobile-first digital menu**, with:

- Low friction  
- Clear navigation  
- Easy access to WhatsApp and Maps  
- Consistent visual identity  

### 🚀 **The Solution**
- Redesigned UX flow (Home → Unidades → Cardápio)  
- Component-based UI structure  
- High-contrast action buttons  
- Micro-animations (typing effect, menu animation, background transitions)  
- Mobile navigation logic (hamburger + overlay)  
- Reusable CSS classes and global structure  

### 🛠 **Technical Implementation**
The project is built with:

- `index.html` (hero, background slideshow, typing animation)
- `sobrenos.html`
- `unidades.html`
- `cardapios/*.html`
- `style.css` (global responsive design + visual identity)
- `digitacao.js` (typing effect with looping sentences)
- `menutoggle.js` (hamburger menu logic)
- `background.js` (animated background slideshow)
- No frameworks, no UI libraries — 100% native JavaScript
